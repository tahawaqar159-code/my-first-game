# My First SFML Game 🎮

This is my first game developed using **C++** and the **SFML (Simple and Fast Multimedia Library)**. The project was created to learn the basics of 2D game development, graphics rendering, keyboard input, and game loops.

## Features

- Built with C++
- Uses SFML for graphics and window management
- Keyboard controls
- Basic game loop
- Beginner-friendly project structure

## Technologies Used

- C++
- SFML 2.5.1
- Visual Studio 2022

## How to Run

1. Clone this repository.
2. Open the project in Visual Studio.
3. Make sure SFML is properly configured.
4. Build and run the project.

## Learning Goals

This project helped me understand:

- Setting up SFML
- Creating a game window
- Handling keyboard input
- Drawing shapes and sprites
- Updating objects in a game loop
